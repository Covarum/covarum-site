Current architecture

What Brian is reviewing

Consumer authentication: Supabase Auth handles identity and sessions.
Primary application data: Supabase/PostgreSQL with owner-scoped RLS.
Financial connectivity: Plaid - disabled in this standalone review.
Application backend: Next.js on Vercel.
Native application: Expo / React Native with Today, Money, Ask, Decisions, and You.
Security boundaries: AWS KMS plus an isolated DynamoDB account-deletion/security authority path.
Financial Life Vault: private Supabase Storage, owner-scoped metadata, signed retrieval, secure export.
Product thesis: connect financial evidence to goals, decisions, documents, and human context so Covarify can identify what matters and recommend one clear next move.
